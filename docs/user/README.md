# User documentation

## What this website does

The Frameshelf landing page introduces **Frameshelf** — a local-first visual reference library for videos and images on Windows — and lets visitors explore a small interactive simulation directly in the browser before requesting beta access.

## Using the interactive preview

The preview runs entirely in your browser with sample artwork and never accesses files on your device. Switch between its three modes using the tabs at the top of the preview window:

1. **Browse:** Filter the sample Wall between **All**, **Videos**, and **Images**, type in **Search filenames**, or combine tag chips. Hover, focus, or tap a card to view details, mark a Favourite, or open the bouncing-ball sample clip in Studio. Use **Reset** to clear active filters.
2. **Organize:** Pick a sample reference on the left, assign it to one or more sample **Boards** (`Lighting references`, `Timing & spacing`, `Night mood`), or toggle its **Favourite** heart. Changes stay in your browser tab for the current visit; **Reset** restores the starting state.
3. **Study:** Step through a 48-frame animation clip one frame at a time (`◀` / `▶` or `Left` / `Right` arrows while the viewer is focused), set **In [** and **Out ]** range marks, toggle **Loop range** (`R`), play/pause (`Space`), and save private **Moments** with notes that jump back to their saved frame.

## Requesting Windows beta access

Frameshelf is currently in an **internal beta for Windows**. Use the **Request access** button in the closing section (or the **Contact** link in the footer) to email the owner directly.
