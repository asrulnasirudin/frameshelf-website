# QA checklist

What must be validated before work counts as done.

- [ ] `PROJECT_SPEC.md` has no TODO or TO CONFIRM left
- [ ] Tests pass (see Commands in `AGENTS.md`)
- [ ] No secrets in tracked files
- [ ] User-visible changes are reflected in `docs/user/`
- [ ] Notable changes are recorded in `CHANGELOG.md`; actual releases have dated Semantic Version entries
- [ ] Works on a phone-width screen
- [ ] Keyboard navigation works
- [ ] No broken links
- [ ] Tested on a clean Windows user profile
- [ ] Type check and tests pass
- [ ] ESLint check passes
- [ ] HTML validates
- [ ] Page works with JavaScript errors surfaced
- [ ] `.agent/CHECKPOINT.md` is current
- [ ] No secret values in source, documents or tests
